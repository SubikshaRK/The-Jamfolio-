# the JAMfolio — Phase 1: Storefront

This is the first working implementation of the JAMfolio, built from the supplied illustration assets.

## Run locally

No build tools or package installation are required.

1. Open this folder in VS Code.
2. Open `index.html` in your browser, or use the VS Code Live Server extension.
3. Click the red door or **Come on in** button to test the current entry interaction.

## What's included in Phase 1

- Existing hand-painted storefront shell as the main scene.
- Editable HTML text over the blank right display panel.
- Responsive layout for desktop and mobile.
- Clickable door and entry button.
- Accessible welcome overlay with Escape-to-close support.
- Reduced-motion support.

## Important notes

- The HTML, CSS and JavaScript are now populated; the original uploaded files were empty.
- The original PNG artwork is preserved in its supplied folders.
- `ASSET-MANIFEST.md` and `asset-manifest.json` are preserved as received. Their documented WebP paths refer to a processed asset set not present in this ZIP; this implementation uses the actual PNG files available here.
- This is a Phase 1 storefront prototype. The interior scene and jam-jar interactions are intentionally not implemented yet.
